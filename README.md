# Jolin Hsu · Portfolio

Live site: https://imjolinhsu.github.io

- `index.html` – Home
- `resume/index.html` – Resume
- `boop/index.html` – Boop case study
- `assets/style.css` – all styling
- `assets/cursor.js` – the pink "View me" / "Coming soon" cursor on project cards
- `assets/img/` – images

To make a project card clickable later: in `index.html`, change its `<div class="card" data-cursor="Coming soon">` to `<a class="card" href="project-name/" data-cursor="View me">` (and its closing `</div>` to `</a>`).
